# D Buy — Jual Akun Digital (by Duta Teladan)

Landing page statis untuk menerima penjualan akun Instagram, TikTok, YouTube, dan Saluran WhatsApp. Semua tombol diarahkan ke WhatsApp admin **0888-8999-904**.

- `index.html`: satu halaman (CSS & JS inline)
- `assets/`: logo, ikon, gambar OG, dan infografis tutorial cek insight (`assets/tutorial/`)

Konfigurasi ada di bagian atas `<script>` di `index.html`: `WA_PHONE`, `PLATFORMS` (tarif kalkulator), dan `SHEET_ID` (testimoni dari Google Sheets).
